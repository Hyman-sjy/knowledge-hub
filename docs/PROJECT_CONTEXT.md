## 四类文件策略

| 文件类型 | 建议策略 | 核心保留内容 |
| --- | --- | --- |
| 程序文件、质量手册 | 层级解析 | 章、节、条款、父级上下文、页码及附件关联 |
| 检验规范、标准 | 条款结构解析 | 适用范围、规格、条件、指标、单位、上下限及引用 |
| Excel 检验表、参数表 | 结构化表格解析 | 合并单元格、多层表头、行列、公式、单位及单元格位置 |
| 普通通知、会议纪要 | 语义段落解析 | 发布与生效日期、接收范围、有效期、替代关系及正式性 |

会议建议不自动升级为正式要求，用户反馈不自动覆盖受控知识。
