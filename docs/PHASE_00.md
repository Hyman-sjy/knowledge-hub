# PHASE 00 · 技术验证准备

状态：待原始工程基线核对，尚未执行。本文从原对话提取验证方向，最终以接收后的任务书及记录的修订为准。

## 进入条件

- [ ] 原始 V1.1 包与执行提示词接收并核对。
- [ ] 技术负责人、业务审核人及样本访问权限确定。
- [ ] 20～50 份代表性文件覆盖四种策略，受控保存且允许用于测试。
- [ ] 样本有效版本、来源、权限、适用范围及预期答案人工核验。

原始测试材料和完整结果存于企业受控环境；公共仓库只提交脱敏汇总及证据索引。

## 评估原则

- 对比使用同一批样本及预期结果，记录解析器、模型和配置，不能仅用演示截图选型。
- 四种策略分别报告结果，暴露表格、数值、版本、权限及无答案问题。
- 门槛、指标分母和排除规则应在正式运行前冻结；不把建议值记作达成值。
- 缺失真实环境时记录“未执行”和阻塞条件，不用模拟成功替代联调。
- G0 是否通过由授权评审人根据原始基线及证据判断，AI 不代签。
