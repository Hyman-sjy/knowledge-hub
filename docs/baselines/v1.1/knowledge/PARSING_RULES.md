# 四类文件解析规则

本文件为 `INGESTION_PIPELINE.md` 的可执行细则。每种策略有独立 parser profile、golden samples 和回归测试。

## 1. 程序文件/质量手册：层级切片
识别章/节/条/款/项；保存编号、父节点、标题路径、页码；子条款附父级上下文；跨页续接；表格/附件/流程图挂接所属条款；修订记录独立抽取。

## 2. 检验规范/标准：条款结构切片
条款独立对象；抽取产品、规格、试验条件、项目、设备、频率、样本量、判定、数值、单位、上下限；表格和附录建立引用；缺失条件标 incomplete；数值由规则/人工核验，不由LLM补造。

## 3. Excel检验表/参数表：结构化表格
保留 workbook/sheet/table/header path/row/column/cell range；处理合并单元格、多层表头、隐藏行列、公式与缓存值；每个值绑定表头、单位、规格条件；空白/0/NA/横线分别处理；复杂表格人工复核。

## 4. 通知/会议纪要：语义段落
按议题/标题/段落/时间切分；提取发布部门、发布人、日期、执行日期、接收范围、有效期、关联文件；区分讨论意见、建议、会议决议、正式批准要求；记录替代关系。

## 5. 通用输出
统一 ParsedElement schema；保留原始文件引用、解析器版本、规则版本、内容哈希和定位。低置信度/结构异常进入 NEEDS_REVIEW。
