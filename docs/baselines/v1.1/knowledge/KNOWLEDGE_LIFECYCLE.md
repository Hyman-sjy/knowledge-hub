# 知识生命周期 V1.1

## 流程
产生（文件/反馈/案例/外部标准）→登记→解析/结构化→来源核验→候选提炼→去重与关联→专业审核→必要验证→授权批准→发布→使用监控→更新/撤回/归档。

## 状态
候选：NEW、DEDUP_PENDING、IN_REVIEW、NEEDS_VALIDATION、APPROVED_FOR_PUBLICATION、REJECTED、PUBLISHED、WITHDRAWN。
文件生命周期另行管理：DRAFT、PENDING_APPROVAL、EFFECTIVE、SUPERSEDED、WITHDRAWN。
两套状态不能合并。

## 发布门槛
必须有来源证据、Owner、适用范围、审核记录、版本和发布批准。AI不得直接发布。发布后建立索引版本；撤回后使当前检索索引失效但保留审计。
