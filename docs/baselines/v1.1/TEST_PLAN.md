# 测试与验收计划 — QKH V1.1

## 1. 测试层
Unit、Integration、Golden Set、Parser Benchmark、Security、UAT、Regression。

## 2. 四类解析测试
A 程序/手册：标题层级、条款编号、父子关系、跨页、附件关联。
B 标准/检验规范：条款、适用产品规格、条件、数值、单位、表格引用。
C Excel：多层表头、合并单元格、隐藏行列、公式/缓存值、空值语义、sheet/cell定位。
D 通知/纪要：时间、发布部门、执行日期、接收范围、讨论意见与正式决议区分、替代关系。

## 3. 知识地图测试
- 业务对象关系是否有证据来源。
- 意图输出是否符合schema。
- 路由是否调用允许工具。
- 缺少产品/规格/时间时是否澄清。
- 权限过滤是否在检索前执行。
- 工具不可用时是否安全失败。

## 4. 反馈沉淀测试
- 原始反馈、问题、答案和证据快照完整保存。
- 重复反馈可聚合但不丢失原始记录。
- 候选知识必须引用来源。
- 候选提炼不能直接发布。
- 审核、验证、批准角色隔离。
- 否定/失败验证作为反例保留。
- 发布后可追溯版本、Owner、审核人和来源。
- 撤回后索引失效，历史审计仍保留。

## 5. 建议验收指标
- Recall@5 ≥ 90%，按文件类型分层报告。
- 关键条款引用正确率 ≥ 95%。
- 已回答问题关键事实正确率 ≥ 95%。
- 当前要求测试中错误版本作为现行证据为0。
- 固定权限测试越权为0。
- 无权威证据/冲突时正确拒答或升级 ≥ 95%。
- 原文定位可用率 ≥ 98%。
- 解析异常均可见、可复核、可重试。
- 反馈写入成功率 ≥ 99%。
- 候选知识未经授权发布次数为0。
以上为目标值，不是已达成事实。

## 6. 阻断项
权限泄露、错误版本作为当前要求、伪造引用、表格数值丢失上下文、候选知识自动发布、审核权限绕过、无法追溯证据，均阻断上线。
