# 协作与共建规范 V1.1

## 角色
- 业务 Owner：确认业务规则、适用范围和黄金答案。
- 文件 Owner：确认来源、版本、权威性和生命周期。
- 知识 Owner：审核候选知识、批准发布/撤回。
- 平台 Owner：架构、API、数据、发布和运维。
- IT/安全：身份、网络、权限、密钥和部署。
- 贡献者：按Issue/PR提交代码、测试和文档。

## Git
main仅保留可运行且已验证版本；按功能分支开发；PR包含目的、改动、测试、风险、迁移和文档。数据库、权限、知识发布策略至少一名维护者审查。

## 知识共建
员工可提交反馈/候选；专业人员审核；知识Owner批准发布。AI提炼不等于审核。每条发布知识必须有来源、适用范围、Owner、版本和审计。否定和验证失败作为反例保留。

## 文件与隐私
真实受控质量文件、客户信息、员工信息和密钥不得提交Git。使用脱敏样本和合成测试数据。
