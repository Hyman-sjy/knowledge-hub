# Roadmap — QKH

## P0 / V1.1：质量知识服务基础设施
- 统一文件主目录、版本、来源、权威性、ACL。
- 四类结构化解析策略。
- 三层知识地图。
- 统一 API、Web + 企业微信入口。
- Dify 编排 + 外部检索服务。
- 反馈 → 候选知识 → 人工审核/验证/批准 → 发布。
- 黄金集和运行监控。

## P1：质量体系文件生命周期
- 文件变更申请、原因、版本比较。
- 关联文件与受影响业务对象识别。
- 部门/岗位影响范围。
- 复用 OA 审批。
- 批准发布、索引刷新、通知、阅读确认、培训确认。

## P2：质量经验知识化
- 8D/CAPA、客诉、过程异常、供应商问题、工艺改善。
- 经验、假设、已验证根因、反例分别建模。
- 专业审核和验证证据。
- 相似案例检索、适用条件和失效边界。

## P3：智能质量协作
- QMS/MES/SPC只读接入。
- 批次、产品、设备、原料、工艺上下文。
- RCA辅助、验证计划建议、闭环追踪。
- AI建议与工程师决策分离。

## P4：企业知识生态
- 其他部门知识域。
- MCP/插件适配器。
- 多应用身份、授权、审计。
- 跨域知识治理、运营指标。
- 仅在关系查询复杂度证明必要时评估知识图谱数据库。
