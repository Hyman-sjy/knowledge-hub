# 知识Owner与运营责任

## 角色
- Platform Owner：平台技术、SLA、发布、备份、安全。
- Domain Owner：知识域分类、质量、指标和运营。
- Document Owner：文件有效性、版本、适用范围、更新。
- Reviewer：专业内容审核。
- Approver/Knowledge Owner：批准候选知识发布、撤回。
- Contributor：员工反馈和补充。

## 最低要求
每个正式知识域、文件和发布知识条目必须有Owner或明确的责任角色。Owner变更必须留审计。

## 运营SLA建议
- 高风险错误/权限问题：立即阻断并升级。
- 错误版本/错误数值：优先级最高，暂停相关知识检索直至修复。
- 普通缺失知识反馈：按周分派。
- 候选知识：设定审核期限；超期提醒，不自动发布。
具体时限由质量主管和IT批准。
