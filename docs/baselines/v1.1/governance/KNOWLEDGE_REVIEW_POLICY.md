# 知识审核政策

## 审核分级
1. 文件元数据/来源：文件Owner确认。
2. 制度/标准条款：质量体系或授权专业Owner确认权威性、适用范围。
3. 技术经验/案例：对应质量、工艺、研发、设备专业人员审核；必要时验证。
4. 正式发布：知识Owner/授权审批人批准。
5. 反例：保留失败证据和条件，不作为成功建议展示。

## 审核结果
ACCEPT_FOR_VALIDATION、REQUEST_CHANGES、REJECT；验证结果 SUCCESS/FAILURE/INCONCLUSIVE；发布 APPROVE/DECLINE。

## 审核证据
记录审核人、时间、理由、引用来源、试验/数据证据、适用范围和版本。
AI摘要必须可回到原始证据。
