# Changelog

## V1.1 — 2026-11-11
### Added
- 三层知识地图：业务对象、需求意图、工具能力。
- 反馈到候选知识的提炼、去重、审核、验证、批准、发布闭环。
- 知识可信状态和正式文件生命周期分离。
- 四类解析策略升级为可测试的工程规范。
- 统一应用接入、身份和权限契约；MCP/插件按需适配。
- 新增知识模型、生命周期、关系、可信等级、反馈分类、Owner、审核政策等文档。
### Changed
- 首期范围补充候选知识提炼与审核；不允许自动发布。
- Dify定位为编排层；解析与检索独立评测。
- 分期调整为五期。
### Preserved
- V1.0全部原始文件和决策保存在 `version-history/v1.0-baseline/`。
