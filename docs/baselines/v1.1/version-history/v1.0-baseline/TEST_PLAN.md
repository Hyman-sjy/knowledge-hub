# 测试与验收计划

## 1. 测试分层
- Unit：解析转换、状态机、ACL、路由、版本过滤、API schema。
- Integration：PostgreSQL、Docling、Dify External Knowledge API、文件导入。
- Golden set：检索与答案证据。
- Security：跨部门越权、身份伪造、提示注入、文件下载绕权。
- UAT：质量人员真实任务。
- Regression：每次解析器、切片、embedding、reranker、prompt 或路由配置变化后执行。

## 2. 解析基准
同一组 20–50 份文件比较 A 现有 Dify、B Docling+自定义结构化切片、C RAGFlow。标注金标准：章节、条款、表格、单位、页码/工作表位置。按 DOCX/PDF/XLSX/扫描件分层报告，不只报总体平均。

## 3. 黄金问题集
建议 100 题：
- 30题：文件定位、精确编号、条款。
- 20题：跨文件检索。
- 20题：产品/规格/工艺适用性。
- 20题：无答案、冲突、废止版本、缺失条件。
- 10题：权限和对抗问题。
每题需由业务专家标注预期文件、版本、条款、关键答案点、应答/拒答规则。

## 4. 建议验收门槛
- Recall@5 ≥ 90%（按文件类型分别统计）。
- 关键条款引用正确率 ≥ 95%。
- 已作答问题关键事实正确率 ≥ 95%。
- 固定测试集当前要求题错误版本命中为 0。
- 固定权限测试集越权为 0。
- 无权威证据/冲突时正确拒答或升级 ≥ 95%。
- 原文定位可用率 ≥ 98%。
- 导入成功率 ≥ 98%，解析异常必须可见并可重试。
- 反馈写入成功率 ≥ 99%。
这些是目标，不是已测结果；小样本通过不代表绝对安全。

## 5. 解析评估指标
结构元素完整率、标题层级正确率、表格表头/行列还原率、条款编号正确率、数值与单位准确率、页码/工作表定位准确率、人工修复时间、解析耗时。

## 6. 阻断缺陷
任何权限泄露、错误版本作为当前要求、伪造文件/条款引用、无法追溯证据、文件原文链接绕过权限，均为上线阻断项。

## 7. 验收报告
记录测试集版本、样本数量、环境、模型/解析器版本、指标分母、失败案例、缺陷严重度、复测结果、业务 Owner 签字。
