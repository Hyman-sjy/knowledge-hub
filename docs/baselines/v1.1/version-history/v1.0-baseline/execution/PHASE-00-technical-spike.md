# PHASE 00 — 技术验证（第1周）

## 目标
在编码主系统前，回答文档解析、检索、Dify外部知识API、身份权限、企业微信入口是否可行。

## 任务
1. 收集20–50份经批准样本，按DOCX/PDF/XLSX/扫描件分类。
2. 选择至少20道专家标注问题，形成初始小型金标准。
3. A：现有Dify解析/切片；B：Docling；C：RAGFlow，生成解析产物。
4. 检查标题层级、表格、条款编号、数值/单位、页码/工作表定位。
5. 建立最小检索比较：精确字段、BM25/FTS、向量、混合、Rerank。
6. 验证私有Dify External Knowledge API契约和身份上下文传递。
7. IT确认企业微信应用、H5、OAuth/可信身份映射可行性。
8. 确认文件下载、原文链接和权限策略。
9. 输出ADR-002/003/004修订建议。

## 交付
- `evaluation/PARSER_BENCHMARK.md` 填写结果。
- 样本清单（不提交真实敏感文件到Git）。
- PoC代码与运行说明。
- Gate G0评审记录。

## 退出条件
不能确认权限传递时，不得开放受限文件问答；解析质量不足时，缩小首期文件类型或增加人工复核。
