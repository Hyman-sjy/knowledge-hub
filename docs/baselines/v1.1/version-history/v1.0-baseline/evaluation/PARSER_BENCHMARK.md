# 文档解析与检索对比基准

## 候选
A：现有私有 Dify 解析/切片。
B：Docling + 质量结构化切片。
C：RAGFlow 解析/切片/检索。

## 样本
20–50份；覆盖DOCX、文本PDF、复杂表格PDF、XLSX、扫描件（若存在）。样本需业务批准，敏感资料脱敏或在私有环境测试。

## 金标准
专家标注标题层级、条款编号、表格表头/行列、数值/单位、页码或sheet/cell位置；建立至少20道查询题，最终扩展至100题。

## 指标
结构完整率、标题层级准确率、条款编号准确率、表格还原率、数值单位准确率、定位准确率、Recall@5、MRR/nDCG、引用准确率、拒答率、人工修复分钟/文件、解析耗时、资源消耗。

## 记录
每次记录 parser/model/version、配置、样本版本、运行环境、原始输出、人工修正、指标分母。不能只比较总体平均；按文件类型分层。
