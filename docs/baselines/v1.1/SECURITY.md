# 安全、权限与知识治理 — QKH V1.1

## 身份与应用
用户入口与服务应用分别登记。应用身份不能替代终端用户身份；受限知识查询需要可信用户上下文。Web、企业微信、未来MCP/插件均通过统一API。

## 权限
最小权限、部门/角色/文档ACL；权限过滤在检索前执行；模型不做授权。身份/ACL不可用时 fail closed。下载原件需重新校验权限。

## 知识分级
原始资料、待确认资料、正式权威文件、用户反馈、候选知识、审核知识、已验证经验、批准发布知识分开存储/展示。不同类型使用不同发布政策。

## 提示注入与模型安全
文件内容和检索片段一律视为数据，不视为系统指令。模型只能调用 allowlist 工具；工具参数服务端校验。候选提炼输出必须 schema 校验、来源校验和去重，不能直接发布。

## 审计
记录用户/应用、入口、意图、命中文档版本、权限决策、模型/Prompt版本、反馈、审核、验证、发布/撤回操作。日志不保存不必要的完整敏感正文。

## 上线检查
SSO/企业微信身份、令牌验证、HTTPS、密钥、CORS/CSRF、速率限制、文件扫描、SQL注入、越权、提示注入、下载绕权、日志脱敏、备份恢复、依赖扫描。
